This wikiHow teaches you how to convert a Microsoft Word document in DOCX format into a DOC Microsoft Word file. DOCX files were introduced in 2007, so versions of Word that still generate DOC files can't open them; luckily, you can use a modern version of Word to convert your DOCX files into DOC files. You can also use an online document converter if you don't currently have access to Microsoft Word. Ways to Convert DOCX to DOC

If you have a version of Word from 2007 or later, you can open any DOCX file and re-save it as a DOC. When saving, choose Word 97-2003Document (or Word 97-2004 Document on Mac) as the file type. Otherwise, you can use an online converter to change a DOCX file to DOC. Steps Method 1 Method 1 of 3: Using Word on Windows Download Article 1

Open the DOCX file in Word. Double-click the DOCX file to open it in Microsoft Word.

You can also right-click the DOCX file, click Open with..., and click Word. 2

Click File. It's on the upper-left side of the Word window. A pop-out menu will appear on the left side of the page. Advertisement 3

Click Save As. This option is in the middle of the pop-out menu on the left side of the window. 4

Double-click This PC. It's in the middle of the window. A "Save As" window will appear. 5

Enter a new name for the DOC file. Type in whatever you want to name the DOC version of your file. 6

Click the "Save as type" drop-down box. It's near the bottom of the "Save As" window. A drop-down menu will appear. 7

Click Word 97-2003 Document. This option is in the drop-down menu. The Word 97-2003 Document format uses the DOC file extension. 8

Select a save location. On the left side of the window, click the folder in which you want to save your document. 9

Click Save. It's in the bottom-right corner of the window. Doing so will save a DOC version of your document in the selected save location.[1]XResearch source Advertisement Method 2 Method 2 of 3: Using Word on a Mac Download Article 1

Open the DOCX file in Word. In most cases, simply double-clicking the DOCX file will open it in Word.

You can also click the DOCX file once to select it, click File, select Open With, and then click Word in the pop-out menu. 2

Click File. It's on the upper-left side of the screen. A drop-down menu will appear. 3

Click Save As…. This option is in the File drop-down menu. Doing so opens the "Save As" window. 4

Enter a new name for the DOC file. Type in whatever you want to call the DOC version of the file. 5

Click the "File Format" drop-down box. It's near the bottom of the window. A drop-down menu will appear. 6

Click Word 97-2004 Document. This option is in the drop-down menu. Doing so selects the DOC file type as your save option. 7

Select a save location. On the left side of the window, click the folder in which you want to save your converted document.

You may instead need to click the "Where" drop-down box and then select a folder from there. 8

Click Save. It's a blue button in the bottom-right corner of the window. Doing so will save a DOC version of your document in the selected save location. Advertisement Method 3 Method 3 of 3: Using an Online Converter Download Article 1

Go to an online converter. There are a number of options, such as CloudConvert, Convertio, and FreeConvert.

In this article, we will go over how to use CloudConvert. However, the steps should apply to just about any conversion site you use, since they are all formatted very similarly. 2

[to Convert](https://to-convert.northlist.shop/to-convert/20260826072.html)

Choose the file types you want to convert from and to. Choose DOCX as the file type you're converting from, and DOC as the file type you're converting to. 3

Choose the file(s) you want to convert. Click the button that says Select File or Choose Files. In the dialog box that pops up, navigate to where you've saved the DOCX file you want to convert. 4

Add the file(s) to the site. Click the file you want to convert, then click Open to upload it to the site. If you want to choose multiple files, you can do this in multiple ways:

To choose multiple files that are next to one another, click the first file you want to upload, press and hold ⇧ Shift, then click the last file you want to upload. All of the files in between these two files will be selected. Let go of ⇧ Shift once you've selected the files.

To choose files that are not next to one another, press and hold Ctrl, then click each individual file you want to add. Once you've selected them all, you can let go of Ctrl. 5

Click Convert. The site will immediately begin converting your file(s) to DOC. 6

Click Download to save your files. Your DOCX files have now been converted to the DOC format. Advertisement Expert Q&A  Search Add New Question Ask a Question 200 characters left
