Generators used to be the “go-to” solution when the power goes out, but with the proliferation of portable power stations, many folks now face the choice: Power station or generator? There are plenty of power stations, like the EcoFlow Delta Pro, with the capacity to be used for home backup. And unlike a generator, they can be used inside your home.

The challenge with power stations is that their batteries need to be recharged. That becomes especially challenging when you’re talking about powering something like an RV, which can’t be connected to power if it isn’t available—when you’re off the grid, for example.

The solution to uninterrupted power for your RV, or when the grid goes down for an extended period, doesn’t have to be a choice between power stations and generators—it may be both. The Case for Pairing a Power Station and Generator

While most power stations can be charged via solar panels, their maximum power output often exceeds the maximum solar input. This means they’ll be running a power deficit—using power faster than the batteries can recover. While solar panels might extend a power station’s runtime, in higher consumption situations it can still eventually run down without another charging option. EcoFlow’s App Is Easy to Use and Provides Helpful Info

Like any other smart device, the EcoFlow Smart Generator 4000 connects to your phone via Bluetooth and WiFi using a mobile app. Here, you can monitor fuel consumption and output, as well as change settings. If connected via WiFi, you can do this from anywhere. Winston Zhou

Pairing the Smart Generator 4000 with EcoFlow’s app allows you to monitor and control generator functions.

Using the EcoFlow app, you can set state-of-charge limits that automatically start the generator to charge the power station and shut it off again when complete. For example, you can set the low limit on the power station at 20 percent—when the state of charge drops down to 20 percent, it automatically starts the generator to charge until it reaches the state of charge you set. In testing, we used several setting combinations and had no issues with controlling the stop and start functions.

The app provides a lot of useful information, as well. It monitors generator fuel usage—for both gas and propane—and provides estimated runtime. You can also set the charging speed, monitor power output, and schedule times to start and stop the generator.

Why Having a Dual-Fuel Generator Is Beneficial

If the grid goes down because of a natural disaster, it may be difficult to get fuel when you need it. Having the ability to run a generator on gas or propane gives you the option to burn the fuel you have or the type that’s easiest to get. You can get up to about eight hours of runtime on a tank of gas, but if you have a 20-pound propane tank—the size most grills use—you can extend that by almost three times, depending on usage. Winston Zhou

While you can use gas or propane, I almost exclusively use the latter on dual fuel equipment because it eliminates stale fuel starting issue over the long term.

It’s important to note that propane doesn’t have the energy density that gasoline does. Because of this, the continuous power output is slightly reduced when using propane, down to 2,900 watts (from 3,200 watts for gasoline). Peak power is rated at 4,000 watts for both, using what EcoFlow calls “X-Boost technology,” which allows output to exceed normal limits for very short bursts to start devices that require more power to start.

The advantage of using propane is that it can be stored for very long periods without breaking down—unlike gasoline, which can evaporate and leave glue-like deposits in the fuel system.
